## 🔄 Automatic Refill System

The mod includes a custom chained refill system designed to make filling seed and fertiliser much quicker and easier.

Instead of manually restarting the refill process after every bag or pallet:

1. Position compatible seed or fertiliser bags/pallets near the ESPRO.
2. Start filling normally with **R**.
3. The ESPRO begins filling from the current source.
4. When that source is empty, the system searches for another compatible nearby source.
5. Refilling continues automatically until the relevant tank is full or no compatible nearby source remains.

There is **no additional Auto Refill toggle or custom keybind required**.

Simply begin filling normally and the chained refill system handles compatible nearby sources automatically.

Combined with the chained refill system, multiple nearby bags or pallets can be used with much less repositioning.

## 📥 Installation

### Farming Simulator 25 — PC

1. Download:

   `FS25_KuhnEspro6000RC_Pro.zip`

2. Copy the ZIP file into:

   ```text
   Documents\My Games\FarmingSimulator2025\mods
   ```

3. **Do not extract the ZIP.**

4. Start Farming Simulator 25.

5. Select your save game.

6. Enable **KUHN ESPRO 6000 RC Pro** in the mod selection screen.

7. Load your save.

8. Find the machine in the **Seeders** category of the vehicle shop.

---

## ⚠️ Important Filename

Keep the mod filename exactly:

```text
FS25_KuhnEspro6000RC_Pro.zip
```

Avoid filenames such as:

```text

```

or filenames containing spaces, brackets or other unnecessary characters.

If your browser adds `(1)` because an older copy already exists in your Downloads folder, delete or move the older download before downloading the new version.

## 🔄 Updating

When installing a newer version:

1. Close Farming Simulator 25.
2. Remove the old `FS25_KuhnEspro6000RC_Pro.zip`.
3. Copy the new ZIP into the mods folder.
4. Make sure there is only **one ESPRO Pro ZIP** installed.
5. Restart Farming Simulator 25.

Existing purchased machines may need to be sold and repurchased if a future update changes shop configurations.
